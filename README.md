# Outcomes — manage outcomes, not agents

Interactive prototype of a multi-agent interface for Claude Code / Codex.

Static site: a single `index.html`, no build step.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. Vercel → Add New → Project → import the repo.
3. Framework preset: **Other**. Build command: empty. Output directory: `./`.
4. Deploy.
